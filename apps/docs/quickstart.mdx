## Quickstart Guide

Get up and running with AstraCollab in just a few minutes. This guide will walk you through setting up your account, creating API keys, and making your first API call.

## Prerequisites

- Node.js 18+ installed
- A code editor (VS Code recommended)
- Basic knowledge of JavaScript/TypeScript

## Step 1: Create an Account

1. Visit [astracollab.app](https://www.astracollab.app)
2. Sign up with your email or GitHub account
3. Create your first organization
4. Choose a plan

## Step 2: Generate API Keys

1. Navigate to the **API Keys** section in your dashboard
2. Click **Create API Key**
3. Give your key a descriptive name (e.g., "Production API Key")
4. Copy the generated API key (you won't be able to see it again)

<Note>
  Keep your API key secure and never commit it to version control. Use environment variables in production.
</Note>

## Step 3: Install the SDK

Choose your preferred SDK:

### Next.js SDK

```bash
npm install @astracollab/nextjs
```

### JavaScript SDK

```bash
npm install @astracollab/js
```

## Step 4: Make Your First API Call

### Using the Next.js SDK

```tsx
import { FileUploaderWithUI } from '@astracollab/nextjs';

function MyComponent() {
  const config = {
    baseURL: 'https://api.astracollab.app',
    apiKey: process.env.ASTRACOLLAB_API_KEY
  };

  return (
    <FileUploaderWithUI
      config={config}
      onUploadComplete={(results) => {
        console.log('Upload completed:', results);
      }}
    />
  );
}
```

### Using the JavaScript SDK

```javascript
import { AstraCollabClient } from '@astracollab/js';

const client = new AstraCollabClient({
  apiKey: 'your-api-key-here'
});

// List files
const files = await client.listFiles();
console.log('Files:', files);

// Upload a file
const fileId = await client.uploadFile({
  file: fileObject,
  fileName: 'example.jpg'
});
console.log('File uploaded:', fileId);
```

### Direct API Call

```bash
curl -X GET "https://api.astracollab.app/v1/files" \
  -H "Authorization: Bearer your-api-key-here"
```

## Step 5: Set Up Environment Variables

Create a `.env.local` file in your project root:

```env
ASTRACOLLAB_API_KEY=your-api-key-here
ASTRACOLLAB_BASE_URL=https://api.astracollab.app
```

## Step 6: Test Your Integration

1. Upload a test file using the SDK or API
2. Verify the file appears in your dashboard
3. Check the file details and metadata

## Troubleshooting

Most first-run issues are one of the following:

<AccordionGroup>
  <Accordion title="401 Unauthorized on every request">
    The key is missing from the header, malformed, or revoked. Confirm the
    header reads `Authorization: Bearer <key>` (with the word `Bearer`), that
    the env variable is actually loaded (log `process.env.ASTRACOLLAB_API_KEY`
    length, never the value), and that the key wasn't revoked in the dashboard.
    Server-side keys created for one workspace can't act on another
    workspace's resources — that returns `403`, not `401`.
  </Accordion>
  <Accordion title="CORS errors in the browser">
    API keys are meant for server-side calls. For browser apps, proxy uploads
    through your own backend (a Next.js route handler or server action) rather
    than shipping the key to the client. The Next.js SDK's components expect
    the key in server-rendered or API-route contexts.
  </Accordion>
  <Accordion title="413 on large uploads">
    The single-request upload endpoint has a size ceiling. Switch to the
    multipart flow — the SDKs handle chunking, presigned URLs, and completion
    for you (see the [file upload guide](/features/file-upload)).
  </Accordion>
  <Accordion title="429 Rate Limited during bulk uploads">
    You're outpacing your plan's hourly quota. Lower concurrency (2–4 parallel
    uploads), honor `X-RateLimit-Reset`, and back off with jitter. Batch
    tuning options are documented in the [Next.js SDK guide](/sdk/nextjs).
  </Accordion>
  <Accordion title="File uploaded but not visible in the dashboard">
    Check that you passed the right `folderId`/`orgId` and that the upload
    fully completed — multipart uploads stay `pending` until the complete call
    runs. Listing files scoped to the wrong folder is the most common cause.
  </Accordion>
</AccordionGroup>
